# 🔐 SecurePass Generator

A simple Python-based password generator that creates strong and customizable passwords based on user preferences.

## Features

* Generate passwords of any length
* Include uppercase letters (A-Z)
* Include lowercase letters (a-z)
* Include numbers (0-9)
* Include special characters (!@#$%^&*)
* Input validation
* Generate multiple passwords in a single session

## Technologies Used

* Python
* Random Module
* String Module

## How It Works

1. Enter the desired password length.
2. Choose whether to include:

   * Uppercase letters
   * Lowercase letters
   * Numbers
   * Special characters
3. The program generates a secure password based on your selections.
4. Optionally generate another password.

## Concepts Practiced

* Functions
* Loops
* Conditional Statements
* User Input Handling
* String Manipulation
* Python Modules (`random` and `string`)

## Example

Enter password length: 12

Include uppercase letters? (y/n): y

Include lowercase letters? (y/n): y

Include numbers? (y/n): y

Include special characters? (y/n): y

Generated Password:

A#7kP!2mQ@9x
