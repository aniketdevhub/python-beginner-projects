# 📝 Command-Line To-Do List Manager

A simple and beginner-friendly **To-Do List Manager** built with Python. This project allows users to manage daily tasks directly from the terminal using a menu-driven interface.

## 🚀 Features

- ➕ Add new tasks
- 📋 View all tasks
- ❌ Remove completed or unwanted tasks
- 🛡️ Handles invalid inputs gracefully
- 🎯 Simple and easy-to-understand code structure

## 🛠️ Technologies Used

- Python 3

## 📖 How It Works

The program provides a menu with the following options:

1. Add Task
2. View Tasks
3. Remove Task
4. Exit

Users can continuously manage their tasks until they choose to exit the application.

## ▶️ Running the Project

1. Make sure Python is installed on your system.
2. Clone this repository or download the source code.
3. Open a terminal in the project directory.
4. Run the following command:

```bash
python todo_list.py
