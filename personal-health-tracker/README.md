# 🏥 Personal Health Tracker

A Python-based Personal Health Tracker that generates a detailed health report using user information such as age, gender, height, and weight.

The application calculates important health metrics including BMI, BMI category, daily water intake recommendation, and Basal Metabolic Rate (BMR).

## 🚀 Features

* Generate a complete health report
* Calculate Body Mass Index (BMI)
* Determine BMI category
* Estimate daily water intake requirements
* Calculate Basal Metabolic Rate (BMR)
* Object-Oriented Programming (OOP) implementation
* Simple menu-driven interface

## 📋 Health Metrics Calculated

### BMI (Body Mass Index)

Measures body weight relative to height.

### BMI Categories

* Underweight
* Normal Weight
* Overweight
* Obese

### Daily Water Intake

Recommended daily water intake based on body weight.

### BMR (Basal Metabolic Rate)

Estimated calories required by the body at rest.
