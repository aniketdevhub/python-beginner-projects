# ⌨️ Typing Performance Analyzer

A Python-based command-line application that measures a user's typing speed and accuracy using randomly selected paragraphs. The program includes multiple difficulty levels and provides real-time performance statistics.

---

## 🚀 Features

- Random paragraph generation
- Easy, Medium, and Hard difficulty levels
- Words Per Minute (WPM) calculation
- Accuracy percentage calculation
- Retry option
- Beginner-friendly code structure
- Uses Python's built-in `random` and `time` modules

---

## 🛠️ Technologies Used

- Python 3
- Random Module
- Time Module

---

## 📖 How It Works

1. Launch the program.
2. Select a difficulty level.
3. A random paragraph is displayed.
4. Press Enter to start the timer.
5. Type the paragraph as accurately as possible.
6. View your results:
   - Time Taken
   - Words Per Minute (WPM)
   - Accuracy Percentage
7. Choose to retry or exit.
