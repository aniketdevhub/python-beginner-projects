# 🎯 Python Quiz Game

A simple command-line Quiz Game built using Python. This project asks the user 10 questions, checks their answers, and calculates the final score based on correct responses.

## Features

* 10 quiz questions
* Score tracking system
* Instant feedback on answers
* Final score display
* Beginner-friendly Python project

## Concepts Used

* Variables
* Conditional Statements (`if-else`)
* Loops
* Functions
* Lists
* User Input Handling
