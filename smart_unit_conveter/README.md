# Multi-Unit Converter

A beginner-friendly Python application that performs multiple unit conversions through a simple command-line interface (CLI).

## Features

- Length Conversion (Kilometers → Meters)
- Weight Conversion (Kilograms → Grams)
- Temperature Conversion (Celsius → Fahrenheit)
- Area Conversion (Square Meters → Square Feet)
- Volume Conversion (Liters → Milliliters)
- Speed Conversion (Kilometers/Hour → Meters/Second)
- Time Conversion (Hours → Minutes)
- Currency Conversion (USD → INR)

## Technologies Used

- Python 3
- Functions
- Loops
- Conditional Statements
- User Input Handling

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/Multi-Unit-Converter.git
```

2. Navigate to the project folder:

```bash
cd Multi-Unit-Converter
```

3. Run the program:

```bash
python main.py
```

## Usage

After running the program, a menu will appear:

```text
===== MULTI UNIT CONVERTER =====

1. Length (KM → M)
2. Weight (KG → G)
3. Temperature (C → F)
4. Area (m² → ft²)
5. Volume (L → mL)
6. Speed (km/h → m/s)
7. Time (Hours → Minutes)
8. Currency (USD → INR)
9. Exit
```

Choose an option and enter the value you want to convert.

### Example

```text
Choose an option (1-9): 1

Enter kilometers: 5

Meters: 5000
```
