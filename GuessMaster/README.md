# 🎯 Number Hunter

A simple Python-based number guessing game where players try to guess a randomly generated number. The game features multiple difficulty levels, helpful hints, and attempt tracking to make the experience more engaging.

## 🚀 Features

- Random number generation
- Three difficulty levels (Easy, Medium, Hard)
- Attempt counter
- "Too High" and "Too Low" hints
- Winning message with total attempts
- Beginner-friendly code structure

## 🎮 How to Play

1. Run the Python program.
2. Choose a difficulty level.
3. Enter your guess.
4. The game will tell you whether your guess is too high or too low.
5. Continue guessing until you find the correct number.
6. Try to complete the game in the fewest attempts possible.
